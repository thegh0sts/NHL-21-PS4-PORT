A fix for a crash reported by a tester.

**Game**
- Fixed a crash during play ("Guest fault ... at guest offset 0x885d71 (thread SimThread)", reported
  on an NVIDIA RTX 3070). The port moves the game's short-lived stack data out of Windows' way, but
  in a few functions it moved only some of the instructions that use a given value: one of them
  then read the value from the wrong place. Instructions that use the same value now always move
  together, or all stay where they are

**Known issues**
- A tester's first launch once stopped while the main menu loaded with "Device lost" (the graphics
  card stopped responding, NVIDIA RTX 3070); the next launch worked. The cause isn't known yet: if
  it happens to you, please send the log from the `logs` folder
- Most modes, and matches played to the end, are untested
- One local player only; no online play; only the European 1.10 version is recognised

**Installing:** unzip into a new folder (or over v0.1.1) and run `NHL21.exe`. Settings and saves in
`%LOCALAPPDATA%\NHL21Native` carry over.

This release contains no game files: you need your own PS4 copy of NHL 21 (CUSA18182, Europe, update 1.10).
