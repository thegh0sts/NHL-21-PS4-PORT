A fix for a crash reported by a tester.

**Game**
- Fixed a crash while loading (reported on an NVIDIA RTX 3070, during a first run): when the game's
  watchdog (HangMonitor) noticed a slow thread, it read that thread's stack at the wrong address,
  because the port didn't report where thread stacks are. The real addresses are now reported

**Known issues**
- What made the watchdog notice a slow thread isn't known yet: probably the shader cache being
  built on a first run. If it happens again the game should now carry on; please send the log
- Most modes, and matches played to the end, are untested
- One local player only; no online play; only the European 1.10 version is recognised

**Installing:** unzip into a new folder (or over v0.1.0) and run `NHL21.exe`. Settings and saves in
`%LOCALAPPDATA%\NHL21Native` carry over.

This release contains no game files: you need your own PS4 copy of NHL 21 (CUSA18182, Europe, update 1.10).
